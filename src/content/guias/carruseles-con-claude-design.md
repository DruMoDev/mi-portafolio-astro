La idea no es pedirle a Claude «hazme algo bonito» y cruzar los dedos. Es darle lo que le darías a un diseñador y luego retocar el resultado.

Qué vas a conseguir:

- Un carrusel con hook claro, una idea por slide y CTA final.
- Un diseño coherente con tu color de marca.
- Un flujo repetible para no empezar desde cero cada vez.
- Un prompt base que puedes copiar y adaptar.
- El paso PRO: montar tu design system una vez para que todo salga on-brand.

## Ten clara la estructura antes de diseñar

Antes de abrir Claude Design, piensa el esqueleto. Esta fórmula suele funcionar:

1. Portada: promesa fuerte.
2. Slide 2: paga rápido la promesa.
3. Slides centrales: pasos, errores, ejemplos o comparativa.
4. Penúltima slide: insight PRO o truco diferencial.
5. Última slide: CTA claro.

Ejemplo de estructura:

```text title="Ejemplo de estructura"
1. Portada: "Haz carruseles PRO con Claude"
2. No le pidas diseño, dale briefing
3. Dile público, objetivo y tono
4. Oblígale a preguntar antes de diseñar
5. Retoca el lienzo, no aceptes el primer borrador
6. Crea tu design system una vez
7. CTA: guarda esto y comenta CLAUDE
```

## Dale un briefing a Claude Design

Puedes empezar un diseño desde cualquier conversación de Claude o desde la pestaña de Artifacts. No empieces con una frase vaga como esta:

```text title="Lo que no funciona"
Hazme un carrusel sobre IA.
```

Eso normalmente produce algo genérico. Dale el contexto completo: tema, público, objetivo, número de slides, formato, estilo, hook y CTA. Usa este prompt base:

```prompt title="Prompt base del carrusel"
Hazme un carrusel para Instagram y TikTok sobre [TEMA].

Formato: vertical 4:5.
Número de slides: [N].
Estructura:
1. Portada con un hook potente de 4 a 7 palabras.
2. Slides de contenido, una idea por slide.
3. Slide final con CTA para guardar, comentar o seguir.

Público: [QUIÉN LO VA A VER].
Objetivo: [QUÉ QUIERO QUE ENTIENDAN O HAGAN].
Tono: claro, directo, útil y en español de España.
Estilo visual: editorial, limpio, moderno, con mucho contraste y buena jerarquía.
Color de acento: [TU COLOR DE MARCA].
Tipografía: potente en titulares, muy legible en cuerpo.

Reglas:
- Sin emojis.
- Nada de párrafos largos.
- Una sola idea por slide.
- Texto grande y fácil de leer en móvil.
- Si necesitas aclarar algo antes de diseñar, pregúntame primero.
```

### Versión corta para copiar

Si ya tienes clara la dirección, esta es la plantilla rápida:

```prompt title="Plantilla rápida"
Hazme un carrusel para Instagram y TikTok sobre [TEMA].

Formato 4:5, [N] slides.

Estructura:
- Slide 1: portada con hook potente de 4 a 7 palabras.
- Slides 2 a [N-1]: una idea por slide, con titular grande y explicación breve.
- Slide [N]: CTA para guardar, comentar o seguir.

Público: [PÚBLICO].
Objetivo: [OBJETIVO].
Tono: claro, directo, útil, español de España.
Estilo: editorial, moderno, limpio, con mucho contraste.
Color de acento: [COLOR].

Reglas:
- Sin emojis.
- Texto grande y legible en móvil.
- Nada de párrafos largos.
- No uses relleno.
- Si falta información, pregúntame antes de diseñar.
```

## Responde sus preguntas con intención

Claude Design te hace preguntas antes de diseñar cuando le falta información: estilo, público, color, tipografía, tono o nivel de detalle.

No contestes rápido. Ahí se decide si el carrusel va a parecer una plantilla más o algo tuyo. Ejemplo de respuesta buena:

```prompt title="Respuesta con intención"
Quiero que se vea premium pero simple. Fondo crema, texto oscuro, acento arcilla. Sin emojis. Puedes usar pequeños iconos o formas geométricas, pero que no parezca corporativo. El público son creadores de contenido y profesionales que usan IA para trabajar mejor.
```

Si tienes marca, dile siempre:

- Color principal.
- Color de acento.
- Si usas logo o no.
- Si quieres estética editorial, tech, minimalista, brutalista, creator, startup o premium.
- Qué cosas no quieres ver.

## Pídele el carrusel entero

Cuando tenga el briefing, pídele una primera versión completa:

```prompt title="Primera versión"
Ahora diseña el carrusel completo con esa dirección visual. Quiero que cada slide tenga una jerarquía clara: titular grande, apoyo breve y mucho aire. Prioriza legibilidad en móvil.
```

Qué reviso en la primera versión:

- La portada se entiende en 1 segundo.
- La slide 2 paga la promesa del hook, no se va por las ramas.
- Cada slide tiene una sola idea.
- El texto no está demasiado pequeño.
- El CTA final pide una acción concreta.
- El color de marca aparece como acento, no como decoración aleatoria.

## Retoca en el lienzo

El primer diseño no tiene que ser definitivo. En el lienzo puedes mover, redimensionar y alinear elementos, cambiar titulares, reducir texto y ajustar colores. También puedes dejar un comentario encima de una parte concreta para pedir un cambio solo ahí.

Mi regla: si tienes que leer una slide dos veces para entenderla, está demasiado cargada.

Pídele mejoras concretas:

```prompt title="Simplificar una slide"
Simplifica esta slide. Deja solo una frase principal y una línea de apoyo. Haz que el titular sea más directo y que el diseño respire más.
```

```prompt title="Portada más contundente"
Haz que la portada sea más contundente. Quiero menos texto, más contraste y un hook que pare al usuario en el feed.
```

## Exporta bien

Cuando esté listo, pulsa **Export** (arriba a la derecha del proyecto). Las opciones son:

- PDF, recomendado para conservar el diseño.
- PowerPoint (PPTX) o Google Slides, útiles si quieres retocar después.
- HTML independiente o un .zip con el proyecto.
- Enviarlo a Canva y otras herramientas.

Si necesitas subirlo como carrusel, convierte el PDF a imágenes PNG o JPG y revisa que cada slide se vea bien en móvil.

> Ojo: no hay exportación directa a PNG. No pasa nada: saca el PDF y conviértelo después a imágenes.

## El paso PRO: crea tu design system una vez

Esto es lo que diferencia un carrusel suelto de una marca reconocible. Si usas siempre los mismos colores, fuentes, logo y estilo, crea un design system dentro de Claude Design. Puedes traerlo de tus archivos de diseño, de lo que subas o de un repositorio.

Incluye:

- Tu logo.
- Tus colores principales.
- Tu color de acento.
- Estilo de titulares.
- Estilo de cuerpo.
- Reglas visuales: sin emojis, fondos limpios, mucho contraste, etc.

Prompt para definirlo:

```prompt title="Definir tu design system"
Quiero crear un design system para mis carruseles. Mi marca trata sobre [TEMA / NICHO]. Mi tono es [TONO]. Mis colores son [COLORES]. Quiero que todos los diseños se vean [3 ADJETIVOS]. Ayúdame a definir reglas de color, tipografía, layout, uso de iconos, portada y CTA final para que cada carrusel sea reconocible.
```

Después, cada vez que hagas un carrusel, dile:

```prompt title="Usar tu design system"
Usa mi design system como base. Mantén la identidad visual, pero adapta la composición al tema de este carrusel.
```

## Checklist antes de publicar

- La portada se lee sin hacer zoom.
- Ningún texto queda pegado al borde.
- El orden de las imágenes es correcto.
- La última slide tiene un CTA claro, con una razón concreta (nada de «sígueme para más» a secas).
- El carrusel funciona sin leer la descripción.
- Lo has revisado en el móvil, no solo en el ordenador.

Errores que evitaría: pedir «un carrusel bonito» sin briefing, meter demasiadas ideas en una slide, usar colores nuevos cada vez y publicar el primer borrador sin retocar.

Claude Design no sustituye tu criterio: te acelera el diseño. La diferencia está en el briefing, en recortar texto con criterio y en la consistencia de marca.
